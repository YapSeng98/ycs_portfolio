Homeset

Floor plan to furnished 3D home tour

A design-to-sale platform for property agents in Malaysia and Singapore. Upload a floor plan, trace it, and get a furnished 3D home that buyers can walk through, view as photoreal 360° "Real View" rooms, and use to contact the agent on WhatsApp.

data model drives the 2D plan, 3D view, photos and 360° rooms
1
per path-traced 360° room on an Apple M2
≈90 s
languages — English, Bahasa Malaysia, 中文
3

What it does

  • Trace walls over an uploaded plan with snapping and exact lengths; rooms and areas (sq ft and m²) are detected automatically
  • Dollhouse view and first-person walk-through with collision, WASD and a phone joystick
  • Path-traced HD photos and 360° Real View panoramas, with doorway markers to step between rooms
  • Publish a tour with MY (REN/REA) or SG (CEA) agent details; share by link, QR code or WhatsApp with a PDPA-consented enquiry form
  • Insights: views, visitors, leads and time spent in each room

How it's built

  • TypeScript monorepo: a core package (schema, geometry, region rules), a framework-free three.js viewer, a Fastify + SQLite API and a React web app
  • One HomeModel JSON drives every view, and every edit is a command — undo/redo now, collaboration and audit later
  • A browser-only build on GitHub Pages implements the same API on IndexedDB
  • Photoscanned CC0 furniture, PBR materials, daylight through windows and ambient occlusion
  • Unit, API and headless-Chrome end-to-end tests

ServiceNow × Claude AI

A natural-language interface to ServiceNow

A web app that lets people work with ServiceNow records in plain English instead of navigating the portal. It explores large language models as an interface layer over enterprise REST APIs — combining ServiceNow expertise with hands-on AI agent development.

What it does

  • Query, create and update ServiceNow records without opening the portal
  • Claude picks the table, filter query and REST method for each request
  • Supports incident queries, change request creation and knowledge base search
  • Readable summaries and tables instead of raw JSON
  • Fallback messages when Claude's output fails validation

What I learned

  • Writing system prompts that constrain an LLM to valid API parameters
  • Designing a JSON output schema an LLM follows consistently across varied inputs
  • ServiceNow Scripted REST — custom endpoints, encoded queries, field selection
  • Validating AI output before it touches an external system
  • The practical power — and limits — of LLMs over structured enterprise APIs

NEXAUTO

Workshop operations for auto repair shops

Vehicle check-in, inspection, quotation, service, payment, parts inventory, purchasing, customer follow-ups and role-based access — in one app that works on phone and laptop. The business rules mirror how a real workshop runs, down to who is allowed to see cost prices.

automated end-to-end checks, all passing
617
roles, with a permission matrix the owner edits live
4

What it does

  • Inspection checklist → printable customer quote → approve or decline, with follow-ups for declined jobs
  • Extra work added mid-job needs approval and blocks payment until it gets it
  • "Money owed" keeps promised payments out of revenue until they actually arrive
  • Inventory with on-hand, reserved and available stock, purchase orders, receiving and suppliers
  • Insights on stalled jobs, stock to reorder and customers worth calling; reports on margin, approval rate and revenue per technician

How it's built

  • Owner, Manager, Advisor and Technician roles — technicians see only their own jobs and never see prices
  • Per-user sign-in, lockout after five failed attempts, 12-hour sessions
  • The whole app is one HTML file with no framework; data is stored in the browser for now
  • Documented data model, process, permission matrix, security review and a Supabase migration plan
  • A jsdom test suite that signs in through the real form and clicks through every process as each role

BizTrack

A business manager on a custom ServiceNow app

A CRM for running a direct-sales business — customers, a partner network, activities, purchases and goals. The frontend is a modern React app; the backend is a custom ServiceNow scoped application with its own REST resources and token authentication, not the stock Table API.

custom tables behind the scoped app

What it does

  • Dashboard with overview stats, a monthly revenue chart and upcoming activities
  • Customer records with per-customer purchase history
  • Partner network with sponsor links shown as an interactive org tree, plus one-tap WhatsApp
  • Activity calendar with a map of locations, WhatsApp invites and bulk upload from a spreadsheet
  • Goals with progress tracking, plus a product catalog for reference

How it's built

  • Vite, React 18 and TypeScript with Tailwind CSS, TanStack React Query and React Router
  • Recharts for charts, Leaflet for maps, React Flow + dagre for the auto-laid-out org tree
  • A ServiceNow scoped app with Script Includes and Scripted REST resources
  • Custom token auth: the session token travels in its own request header
  • Records are scoped to the owner and their downline; activities are shared

Daily Brief

Turns an AI-written work brief into tasks

Paste the daily AI summary of your mailbox and the app sorts it into what's pending you, what you're waiting on, meetings and FYI — then sends the items you'll handle straight into the Personal Planning System as real tasks.

brief layouts it can read, from a JSON block to free-text reports
5
login shared with the Planner
1
days before old briefs, dismissed items and history are cleaned up
30/90/180

What it does

  • Reads several brief layouts — a structured JSON block first, then ownership, priority and executive reports
  • Splits items by ownership: pending you, owned by your team, or waiting on others
  • Keeps each item's email trail — subject, last sender, age and how confident the action is
  • "Take" creates a real Planner task; edits and done-state flow both ways
  • Stores your own AI prompt per account, so it's on every device

How it's built

  • React 19, TypeScript and Vite on Supabase with row-level security
  • Shares the Planner's Supabase project and sign-in
  • Writes tasks only through the Planner's own sync RPC, so revisions stay consistent across devices
  • Deterministic task IDs per account and item — taking an item again updates the same task
  • Live updates over Supabase Realtime; Vitest regression tests on made-up sample briefs

Personal Planning System

Vision → Year → Quarter → Month → Week → Day

A planning app that installs on phone, iPad and laptop and works fully offline. Goals at every level roll up automatically, and an optional AI layer drafts daily briefings and reviews. It began on a ServiceNow developer instance and moved to Supabase in September 2026.

What it does

  • Today view with an AI-drafted briefing, habit rings with streaks and time-blocked tasks
  • Finishing a task moves its week goal, which averages up to month, quarter and year
  • Week and month planning, plus a Jira-style board with drag and drop
  • Habit heatmaps; daily, weekly, monthly and yearly reviews pre-filled with your stats
  • Sketches, analytics, Cmd/Ctrl+K search and recurring tasks

How it's built

  • React, TypeScript and Vite, installable as a PWA
  • The UI reads and writes IndexedDB (Dexie); an outbox engine syncs to Supabase, last write wins
  • Postgres schema with row-level security and server functions for sync and goal rollups
  • An optional Cloudflare Worker proxies AI calls — the app works fine without it
  • Migrated from a ServiceNow backend to Supabase in September 2026

Personal Finance Money Tracker

Budgets, bills and goals — with alerts on Telegram

Track transactions across currencies, hold budgets and savings goals, tick off the bills you pay each month, and get a Telegram message when a budget or bill needs attention — all from a single HTML file on GitHub Pages. It started on a ServiceNow developer instance and now runs on Supabase.

currencies — SGD, USD, AUD, MYR, USDT
5

1
job checks budgets and bills, then alerts on Telegram

What it does

  • Accounts in several currencies, with a home-currency total at the day's exchange rates
  • Per-currency budgets with rollover, custom alert thresholds and a "plan from salary" allocator
  • A monthly bills checklist, savings goals linked to accounts and net worth over time
  • Import a bank's CSV statement; export monthly statements as PDF, Excel or CSV
  • Optional Groq AI spending insights using your own key

How it's built

  • Vanilla JS, HTML and CSS in one file — opening it is running it
  • Supabase Postgres with row-level security and Supabase Auth sessions
  • A Deno Edge Function sends Telegram alerts, triggered nightly by pg_cron
  • A localStorage cache makes loads instant and keeps it usable offline
  • Automated tests for the bills and alerts logic

The whole app follows your phone: the palette tracks the time of day, the moon is the real moon, and local weather falls across the page.
